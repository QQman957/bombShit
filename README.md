# 🚽 屎马桶炮 (Poop Toilet Cannon)

一个用马桶发射大便打苍蝇的小游戏。**纯 Canvas2D 矢量绘制，零依赖，单文件**。

## 在线试玩

👉 **https://qqman957.github.io/bombShit/**

## 玩法

| 操作 | 说明 |
|---|---|
| 移动鼠标 | 瞄准（虚线预测弹道） |
| 按住左键 | 蓄力，松手开炮 |
| `←` `→` | 微调角度 |
| `空格` | 蓄力 |
| `M` | 静音 |
| `Esc` | 退出关卡 / 返回 |

## 🔥 狂射模式

连击攒到 **6** 就进入狂射：

- 蓄力几乎瞬间完成（0.85s → 0.10s）
- **按住鼠标自动连发**，每 0.13 秒一发
- **分数翻倍**（叠加在连击倍率之上）
- 打空不掉连击，每次命中续时长
- 全屏金色调，马桶里的水变金色，准星变金

打空会把连击窗口压到 1.4 秒 —— 够你补一记快射，但不够再蓄一次满力。

## 关卡

8 关，四种目标类型，星级评定，进度存本地：

| 关 | 目标 | 机制 |
|---|---|---|
| 1 热身 | 打掉 10 只 | — |
| 2 加速 | 限时 50 秒打 18 只 | 提速 |
| 3 黄金苍蝇 | 打掉 7 只金苍蝇 | 金苍蝇加时 1.5 秒 |
| 4 穿堂风 | 打掉 20 只 | **横风**会吹偏弹道 |
| 5 连击秀 | 打出一次 10 连击 | 连击压力 |
| 6 障碍赛 | 打掉 24 只 | **摆动的卷纸会挡炮弹** |
| 7 神射手 | 命中率 ≥75%（至少 14 发） | 禁止乱喷 |
| 8 终局 | 打掉 34 只 | 狂风 + 4 个障碍 |

星级按剩余时间结算，解锁下一关。

## 实现要点

- **零依赖**：全部用 Canvas2D 路径绘制，没有一张外部贴图，没有构建步骤
- **程序化音效**：WebAudio 合成放屁声（白噪声过带通 + 低频抖动）、溅射、命中、通关号角
- **镜面反射**：镜子里能看到飞过的苍蝇和炮弹的倒影
- **命中顿帧**：击杀时光阴短暂停滞，打击感来源
- **挤压拉伸**：开炮瞬间马桶横向撑开、纵向压扁

## 本地运行

直接用浏览器打开 `index.html` 即可，不需要服务器。

> 通过 `file://` 打开时，部分浏览器会限制 `localStorage`，导致星级进度无法保存。
> 起个本地服务就正常了：`python -m http.server`
